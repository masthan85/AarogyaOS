# Product backlog

This is the consolidated backlog. It merges the open items scattered through the earlier backlog, the operations runbook, the security notes, the README status table and the clinical safety log, and adds items found while reviewing the code for this documentation set. The source repository contains no issue tracker and no `TODO` or `FIXME` comments, so these documents were the only sources.

How to read it. **Status** says what exists today (see `12-FEATURE-STATUS.md`). **Priority** is P0 (blocks any use with real patients), P1 (needed for a safe, supportable pilot), P2 (valuable, can follow the pilot), P3 (nice to have). **Phase** refers to `14-ROADMAP.md`: 1 Validate, 2 Pilot-ready platform, 3 Knowledge and interoperability, 4 Expansion. Items marked "input needed" cannot proceed without something only the owner can supply (an account, a licence, a decision, a reviewer).
