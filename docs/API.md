# API

Base path `/api/v1`. OpenAPI is generated by FastAPI (`/docs`, `/openapi.json`; disabled in production).
Errors follow a problem-details shape: `{type, title, status, detail, correlation_id}`.
Every response carries `X-Request-ID`; send one to correlate client and server logs.

## Phase 1 endpoints
| Method & path | Permission |
|---|---|
| `POST /auth/login`, `/auth/refresh`, `/auth/logout` | public |
| `GET /auth/me` | authenticated |
| `POST/GET /organisations` | `platform:organisations` |
| `GET /organisations/current` | `org:read` |
| `GET/POST /facilities`, `GET/PATCH /facilities/{id}` | `facility:read` / `facility:manage` |
| `GET/POST /departments` | `department:read` / `department:manage` |
| `GET/POST /users`, `GET /users/{id}`, `PUT /users/{id}/roles`, `POST /users/{id}/deactivate` | `user:read` / `user:manage` |
| `GET /roles` | `role:read` |
| `GET /audit-logs` | `audit:read` |

Planned conventions (not yet implemented): `Idempotency-Key` on mutating POSTs, cursor pagination,
optimistic concurrency via `version`.
